# Spec: Tiered (cascade) code review for drovr

**Run:** `tiered-review` · **Worktree:** `.drovr/wt/tiered-review` · **Branch:** `drovr/tiered-review`

## Problem

`drovr code-review run` spawns one read-only reviewer per angle (`correctness`, `security`,
`error-handling`, `type-design` — `cli/src/config.rs:436`), all on the same expensive model, over
the whole `base..head` range. Cost scales with `angles × range size`. A cheap-model-first cascade
is the obvious saving and the obvious way to ship a silent regression in review quality: a cheap
tier's false negative can be unrecoverable, and a `Clean` produced that way is byte-identical to a
real one. This run is a measurement with a feature attached, not a feature with a measurement
attached.

## Decisions

### 1. Unit of escalation is measured, not chosen up front (`decisionrule: measure-first`)

The design question — route by explored-context, by angle, or by file — is resolved by a
pre-registered decision rule, not by argument. **Task 0** instruments expensive-tier reviews on a
sample of fixtures and reports the cost split `E/(E+D)` (E = exploration: tool calls outside the
diff; D = diff-reading and finding-writing), per-fixture, not just as a mean.

| measured `E/(E+D)` | primary design |
|---|---|
| ≥ 0.60 | cheap-as-explorer (cheap tier builds a context bundle; expensive tier reviews the whole diff with it) |
| ≤ 0.30 | per-file routing (router assigns cheap/expensive per file) |
| 0.30 – 0.60 | angle routing (cheap tier owns angles whose judgement is local) |

Angle routing is additionally evaluated as a composable second stage regardless of which primary
design is selected — it is orthogonal to the ratio. Per-file routing is run as a measured control
arm regardless of which design the rule selects, so the spec can report what it would have cost
and missed rather than assume it away.

**Reason:** each design's viability depends on where review cost actually goes, which is unknown
until measured; committing to a design before Task 0 runs would be choosing the answer before the
question is asked.

### 2. The degrade invariant (binds every design)

> A cheap-tier failure must degrade to the baseline — a full expensive review — never to less
> review than the baseline would have given.

Router unavailable, timed out, crashed, out of context, unparseable, naming a unit outside the
range, or silently omitting a unit — every one takes the degrade path. There is no code path from
"the cheap tier had a problem" to "less review happened". Per design, "degrade" means: per-file/
whole-change routing → that unit escalates; angle routing → that angle re-runs on the expensive
tier; cheap-as-explorer → the expensive tier explores for itself, exactly as today.

Designs differ in whether they have an *unrecoverable*-miss class at all (per-file and
whole-change do; angle routing and cheap-as-explorer, whose failure degrades to baseline, do not),
and the ship bar (decision 5) is set from that fact.

### 3. Class-3 defects gate on conditional recall, not absolute detection (`class3gate: gates-conditional`)

Three ground-truth classes, never pooled into one recall figure: class 1 (human review comment
that caused a same-PR change), class 2 (accepted bot review comment that caused a change — the
acceptance filter is what makes this non-circular: a human agreed and changed the code), class 3
(post-merge fix/revert/regression-fix of code a PR introduced — review missed it).

For classes 1, 2, and stratum D, the expensive tier found the defect by construction. Class-3
defects were missed by review, so the expensive tier may miss them too, and a cheap tier cannot be
penalized for failing where the expensive tier would also fail. Two numbers are reported:

- **Conditional recall** (gates): of the class-3 defects the expensive tier finds, how many
  survive the cascade.
- **Expensive-tier absolute detection rate on class 3** (does not gate): reported as the run's
  most interesting scientific output — the ceiling of the review system as a whole.

### 4. Stratum D is scored as two stratified cells, never summed (`corpus: both-stratified`)

Stratum D (`~/.local/share/drovr/runs/skill-stickiness/`: 376 per-angle findings files, 100
panels, 22 tasks) splits into `D-rs` (79 blocking `.rs` findings) and `D-md` (51 blocking `.md`
findings), measured and reported separately. **The ship bar must pass on `D-rs` alone**; `D-md` is
reported with its own interval and cannot rescue a failing `D-rs`. Findings carry their angle,
which is what makes the per-angle premise of angle routing testable.

**Reason:** reviewing Rust and reviewing prose are different tasks; a cheap tier could be good at
one and useless at the other, and pooling would hide that.

### 5. Ship bar shape is set by failure mode, not uniform (`barshape: by-failure-mode`)

- **Designs with an unrecoverable-miss class** (per-file, whole-change triage): recall ≥ 0.98
  with Wilson 95% lower bound ≥ 0.95, target N ≥ 142 per gated cell — a miss there is a defect
  nobody ever looks at again.
- **Designs whose failure degrades to baseline** (angle routing, cheap-as-explorer): non-inferiority
  against the unaided expensive panel, cascade recall LB ≥ 0.90 of the unaided panel's point
  estimate, target N ≥ 69 — the failure is a cost regression, not a lost defect, so demanding 0.95
  LB there buys nothing and costs a corpus.

Going above LB 0.95 for the unrecoverable designs is not adopted: the next tier (LB ≥ 0.97, N ≥
239 for a two-miss tolerance) buys a 0.02 tightening of a bound whose real uncertainty is dominated
by corpus-construction choices, not sampling error.

Gate order, applied in sequence: **0.** N floor met, else the cell is reported null. **1.**
Instrument discriminates (below, decision 6). **2.** The recall bar above. **3.** Escalation/skip
rate leaves a real saving. **4.** Measured end-to-end cost < 0.80× the non-cascade panel. Bars 1
and 2 are the ship decision; failing 3 or 4 ships the code behind `enabled = false` with the
negative economics written up. Precision, hint quality, context completeness, and class-3 absolute
detection are reported but are not decision inputs.

**N is pooled across strata within one `(model × class)` cell** (not per `(model × stratum ×
class)`, which would be 24 unreachable cells) — pooling across strata buys power; pooling across
*classes* is never done (decision 3's classes are never pooled). Per-stratum numbers are always
reported alongside; if per-stratum recall is more heterogeneous than sampling explains, the pooled
figure is not reported as the headline and the discrepant stratum is reported as its own finding.

### 6. Discrimination and stopping controls

Two synthetic, free controls bracket every metric per stratum and per class: NULL (everything
cleared: recall 0, saving maximal) and FLOOD (everything escalated: recall 1.0, saving 0). A real
cheap tier must land strictly inside the bracket on both axes, or those fixtures are rebuilt before
scoring. **Positive control:** re-running the expensive tier on a sample must re-find recorded
class-1/2 defects at a high rate, or the fixtures — not the cheap tier — are considered broken.

**Dev/held-out split** assigned before any cheap-tier prompt is written, at task/PR level (no diff
in both sets). Held-out is scored once, after the prompt is frozen and its `git hash-object`
recorded. There is deliberately no `blind-map.json`: the threat this run defends against is prompt
overfitting, not scorer bias (scoring is set membership, no human judgement), and the split alone
is the control for that threat.

### 7. Egress constraint withdrawn; provenance retained for publishing only (`data handling`)

Qwen is self-hosted: there is no third-party egress and no restriction on which model reads which
stratum. The earlier per-model egress constraint (and the two-legs structure it forced) is
withdrawn as based on a mistaken premise.

**What is retained, because it was always about publication, not model access:** `sauyon/drovr` is
public; `modularml/modular` and `quitesh/quite-app` are not. Private fixtures and probe transcripts
live outside any checkout (`~/.local/share/drovr/cascade-corpus/`). Only aggregates (recall,
precision, counts, analysis) are committed — no diffs, source excerpts, file paths, or defect
descriptions detailed enough to reconstruct internal design from the private repos.

Every fixture carries `provenance: Public | Private`, assigned at harvest from the source repo's
GitHub visibility, never from a path convention. A fixture's body is reachable only through an
accessor requiring a token proving the destination was checked; the write guard refuses to write
`Private`-derived content to any path resolving inside a git checkout after canonicalisation
(closes the symlink-out-and-back-in case). The write guard ships with tests in the same change,
including the symlink-escape case. **Not closed:** a human running an ad-hoc command outside the
harness.

### 8. Corpus design

Full factorial, no legs: `router_model ∈ {qwen, sonnet}` × `stratum ∈ {D, M, Q, N}` × `class ∈ {1,
2, 3}`, plus per-file routing as a control arm. The ship decision is per router model — a
sonnet-routed cascade and a qwen-routed cascade are different products, tracked as separate config
values (decision 9).

Strata: **D** (drovr, `skill-stickiness` artifacts, public), **M** (`modularml/modular`, private,
carries class 1), **Q** (`quitesh/quite-app`, private, class 1 too thin to carry alone), **N**
(`neovim/neovim`, public, third language, reproducible off this machine — chosen over
`ghostty-org/ghostty`, which yielded fewer review comments per merged PR in a same-session
measurement).

Class 1/2 attribution is verified per fixture, never assumed from comment existence alone:
`commits == 1` disqualifies a PR (a single-commit PR cannot contain a comment-driven fix commit); a
later commit in the same PR must touch the commented file; docs-only PRs are excluded.

Class 3 pipeline: candidate fix commits found via `git log -i --grep` for
`revert|regression|broke`; `git blame` the lines the fix deleted or replaced, at `fix^`; require a
single introducing commit (fan-out is rejected as not cleanly attributable); that commit's PR at
pre-merge state is the fixture, the fix commit's diff states the defect. Attrition is reported at
every stage (candidates → single-attribution → adjudicated-as-defect).

### 9. Freezing and ledger

Stratum D and N fixtures are frozen by a MANIFEST (shape of `docs/skill-evidence/arms/MANIFEST.md`):
`git hash-object --no-filters` blob SHAs, a commit cell that must contain the blob at the recorded
path, header-resolved columns, a test re-checking every row. Strata M and Q are frozen the same way
in the private corpus directory, with only the row count and the manifest's digest committed.

Every cheap-tier invocation is counted in an append-only ledger with per-stage ceilings; the
ledger's arithmetic is checked by a test. Retries count toward the ledger.

**Guard-with-artifact applies throughout this run:** every set it extends — config keys, the
`mode` enum, the cheap tier's output vocabulary, ledger columns, MANIFEST rows, fixture list, the
class enum — gets its guarding test extended in the same change that extends it.

## Interfaces and contracts

- **Config surface** (`[review.cascade]` in drovr's TOML config):
  ```toml
  [review.cascade]
  enabled = false            # default; stays off for the duration of this run regardless of result
  mode = "<undecided>"       # explorer | angle | file | change — set by Task 0's decision rule (decision 1), not before
  cheap_agent = "opencode"
  cheap_model = "ko-ag/qwen3.6-35b-abliterated"
  timeout_ms  = 120000       # expiry takes the degrade path (decision 2)
  ```
  `router_agent`/`router_model` are separate config keys from the expensive-tier equivalents,
  because the ship decision is per router model (decision 8).
- **Cheap-tier execution contract:** headless only — `opencode run --agent plan -m <model>`, not a
  herdr pane. `opencode run`'s stdout is a subprocess pipe, which is what
  `cli/src/code_review.rs:1`'s no-scrape rule requires; a cold `opencode` reviewer pane swallows
  its seed and the panel cannot converge (`docs/known-issues.md:3437`), so the pane path is closed
  for this backend, not for style reasons. Read-only via `--agent plan` with `--auto` absent; the
  existing `readonly_displace` protection (`cli/src/config.rs:589`) runs first, unmodified.
  Verified working this session.
- **Cheap-tier output contract:** under every design, the cheap tier's output is either a routing
  decision or a context bundle — never a finding that reaches a verdict on its own.
- **Fixture contract:** every fixture carries `provenance: Public | Private` (decision 7); D and N
  fixtures ship a MANIFEST with blob-SHA verification (decision 9); ground-truth class is one of
  `{1, 2, 3}` per §"Decisions/3" and is never pooled across classes in a reported figure.
- **Cascade integration point:** a new stage in `cli/src/code_review.rs`, shipped behind
  `enabled = false`, alongside the existing per-angle `AgentLaunch` fan-out driven by `cfg.angles`
  (`cli/src/config.rs:436`).
- **Ledger contract:** append-only, per-stage ceilings, arithmetic covered by a test, retries
  counted.

## Deliverables

(1) Task 0 cost instrumentation and its report. (2) Relational-defect recall ceiling for per-file
routing, computed from class-3 fixtures (fix-commit files vs. introducing-PR files). (3) Corpus
harvesters for class 1/2 attribution and class 3 blame-back, each reporting attrition. (4)
Fixtures + MANIFESTs; D and N committed, M and Q private. (5) `provenance` typing, write guard, and
tests. (6) Cheap-tier implementation for the design Task 0 selects, plus the per-file control arm.
(7) Cascade stage in `cli/src/code_review.rs` behind `enabled = false`. (8)
`docs/cascade-evidence/results.md`: controls, dev numbers, one held-out score per
`(model × stratum × class)`, each gate in order, ship decisions, stated limitations, aggregates
only — no private-repo content. (9) Run ledger.

## Out of scope

- Flipping `enabled` to `true` by default.
- Changing the angle set, severity model, or the merge/resume path.
- A second measurement instrument beyond this run's design.
- Fixing the `opencode` cold-pane seed-swallowing bug (`docs/known-issues.md:3437`) — the headless
  cheap tier routes around it; the pane bug stays open and documented, not fixed, by this run.
- Any tier between qwen and opus (e.g. an intermediate-cost model).

## Notes carried for the record

`ko-ag/qwen3.6-35b-abliterated` is an abliterated build (safety tuning removed). This is recorded
because omitting it would describe a different experiment; it does not change scope, since under
every design in this spec the cheap tier's output is a routing decision or context bundle, never a
verdict-bearing finding (see Interfaces, cheap-tier output contract).
