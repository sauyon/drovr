# Tiered (cascade) code review for drovr

**Run:** `tiered-review` · **Worktree:** `.drovr/wt/tiered-review` · **Branch:** `drovr/tiered-review`

## 1. Problem

`drovr code-review run` spawns one read-only reviewer per angle (`correctness`, `security`,
`error-handling`, `type-design` — `cli/src/config.rs:436`), every one on the same expensive model,
over the whole `base..head` range. Cost scales with `angles × range size`. A cascade (cheap model
first, expensive model only where warranted) is the obvious saving, but a cheap tier's false
negative is unrecoverable — nothing downstream re-checks what it waved through, and a `Clean` it
produces is byte-identical to a real one. This run is a **measurement with a feature attached**, not
a feature with a measurement bolted on: no cascade design ships without evidence it doesn't quietly
regress recall.

## 2. Binding invariant

> A cheap-tier failure must degrade to the baseline — a full expensive review — never to less
> review than the baseline would have given.

Router unavailable, timed out, crashed, out of context, unparseable, naming a unit outside the
range, or silently omitting a unit: all take the degrade path. There is no code path from "the
cheap tier had a problem" to "less review happened". Instantiation depends on the routing unit
(decided in §3):

| design | degrade target on cheap-tier failure |
|---|---|
| per-file / whole-change routing | that unit escalates to the expensive tier |
| angle routing | that angle re-runs on the expensive tier |
| cheap-as-explorer | the expensive tier explores for itself, exactly as today |

Per-file and whole-change routing have no failure mode that satisfies this without an
unrecoverable-miss class remaining (a routed-away unit is never looked at again); angle routing and
cheap-as-explorer do not have this class, since the expensive tier still touches everything. This
distinction is load-bearing for the ship bar (§7).

## 3. Decision: routing design is measurement-gated, not chosen up front

**Decided (`decisionrule: measure-first`).** Before any cascade design is built, Task 0 instruments
a sample of expensive-tier reviews and reports the cost split as `E/(E+D)`:

- **E — exploration:** tool calls searching or reading outside the diff (grep, unchanged-file reads,
  call-site follows, test reads).
- **D — diff-reading and finding-writing.**

Reported as a per-fixture distribution, not only a mean.

**Pre-registered mapping (chosen before the number is known, since that's the only time it can be
chosen honestly):**

| measured `E/(E+D)` | primary design |
|---|---|
| ≥ 0.60 | cheap-as-explorer (§4.1) |
| ≤ 0.30 | per-file routing (§4.4) |
| 0.30 – 0.60 | angle routing (§4.2) |

Angle routing is additionally evaluated as a composable second stage in all three branches — it is
orthogonal to the ratio and can layer on whichever primary design is selected.

## 4. Candidate designs — what each binds

### 4.1 Cheap tier as explorer

Cheap model builds a context bundle (call sites, related tests, invariants, prior art); expensive
model reviews the whole diff seeded with that bundle. Nothing is skipped — no unrecoverable-miss
class. **Ship metric: non-inferiority of end-to-end defect recall against the unaided expensive
panel on the same fixtures** — this measures anchoring (a bundle that looks sufficient causing the
reviewer to explore less) directly, without needing a definition of "complete". Context completeness
is a diagnostic only, never the bar.

### 4.2 Angle routing

Cheap tier takes angles judged local; expensive tier keeps correctness/security. Maps onto the
existing per-angle `AgentLaunch` in `code_review_run` — smallest diff of any candidate. Insensitive
to the E/D ratio. No unrecoverable-miss class: every angle is still reviewed by someone.
"Local judgement" per angle is measured, not assumed, using stratum D's per-angle findings (§5.6).

### 4.3 Whole-change triage

One skip/deep-review decision per change. **Decided: not a general mechanism.** Recommended only as
a narrow, conservative complement on changes where near-certainty is available (dependency bumps,
generated files, pure formatting), expressed as a rule, never a model judgement. Not built as the
general design regardless of Task 0's result.

### 4.4 Per-file routing — control arm

Retained in the run regardless of what §3's rule selects, so the spec reports its actual cost and
miss rate rather than assuming them. **Deliverable:** empirical recall ceiling — for every class-3
fixture, compare files the *fix* commit touched against files the *introducing* PR changed; a defect
whose fix lands outside the introducing diff is one no per-file router could have routed to. That
fraction is the ceiling for any per-file design, computed from real defects.

## 5. Corpus — contract

### 5.1 Ground-truth classes (never pooled into one recall figure)

| class | signal |
|---|---|
| 1 | human review comment that caused a change in the same PR |
| 2 | **accepted** bot review comment (human author changed code in response) |
| 3 | post-merge fix/revert/regression-fix of code a PR introduced — review **missed** it |

Class 1/2 attribution requires: PR has `commits > 1` (a single-commit PR cannot contain a
comment-driven fix commit); a later commit in the same PR touches the commented file; docs-only PRs
excluded. Verification method is recorded per fixture.

Class 3 pipeline: find candidate fix commits via `git log -i --grep` for `revert|regression|broke`
and kin → `git blame` the lines the fix deleted/replaced at `fix^` → require a single introducing
commit (fan-out is rejected as non-attributable) → that commit's pre-merge PR state is the fixture.
Validated end-to-end on quite-app (`cb1adad` → `sip_clone.rs` → blame resolves to `55b80032`).

### 5.2 Strata (full factorial: `router_model × stratum × class`, no "legs")

| stratum | source | visibility | classes carried |
|---|---|---|---|
| D — drovr | `skill-stickiness` run artifacts | public | drovr-specific, §5.3 |
| M — modular | `modularml/modular` | private | 1, 2, 3 |
| Q — quite-app | `quitesh/quite-app` | private | 2, 3 (class 1 too thin — 13 comments, all one human) |
| N — neovim | `neovim/neovim` | public | 1, 2, 3 |

Every stratum is probed by every router model — model access is not a stratifying factor (§6).
Results are reported per repo and per class; a thin cell is reported thin, never merged into a
neighbour.

### 5.3 Stratum D — decided (`corpus: both-stratified`)

Source: `~/.local/share/drovr/runs/skill-stickiness/` — 376 per-angle findings files, 100 panels, 22
tasks, all base/head SHAs resolvable from this worktree's shared object database. 131 blocking
findings: 79 `.rs`, 51 `.md`, 1 `.json`. Findings carry their angle (feeds §4.2's per-angle
measurement). Labels: *verified-real* (fix landed, or written up in `docs/known-issues.md` — the
only set that feeds the ship bar), *unverified* (reported, not scored), *rejected* (excluded, reason
recorded).

**Decided:** scored as two stratified cells, `D-rs` (79 blocking findings pre-filter) and `D-md`
(51), reported separately and never summed. **The ship bar must pass on `D-rs` alone**; `D-md` is
reported with its own interval and cannot rescue a failing `D-rs`. (This decision went against this
spec's own `rs-only` recommendation; recorded per §10.)

## 6. Data handling — decided, binding

**Decided:** the prior egress constraint (qwen restricted from certain strata) is withdrawn in full,
including the two-legs structure it forced. Qwen is self-hosted — no third-party egress, no
restriction on which model reads which stratum.

**What is unchanged:** `sauyon/drovr` is public; `modularml/modular` and `quitesh/quite-app` are
not. Private fixtures and probe transcripts live outside any checkout
(`~/.local/share/drovr/cascade-corpus/`). Only aggregates are committed (recall, precision, counts,
analysis) — no diffs, source excerpts, file paths, or defect descriptions detailed enough to
reconstruct internal design from those two repos.

**Contract — provenance type + write guard.** Every fixture carries `provenance: Public | Private`,
assigned at harvest from the source repo's GitHub visibility (never from a path convention or
recollection). The write guard refuses to write `Private`-derived content to any path resolving
inside a git checkout, post-canonicalisation (so a symlink out of the corpus directory and back into
the repo does not defeat it). Shaped after `ReviewOutcome::EmptyRange` (`cli/src/code_review.rs:94`):
a fixture's body is reachable only through an accessor requiring a token proving the destination was
checked — the guard is a type, not a call-site check. Ships with tests in the same change, including
the symlink-escape case. The egress guard is removed with its premise; `provenance` keeps a single
consumer.

**Not closed by this design:** a human running an ad-hoc command outside the harness.

## 7. The measurement — contract

### 7.1 Arms

`router_model ∈ {qwen, sonnet}` × `stratum ∈ {D, M, Q, N}` × `class ∈ {1, 2, 3}`, design fixed by
§3, per-file routing run as a control arm alongside. **The ship decision is per router model** — a
sonnet-routed cascade and a qwen-routed cascade are different products, so `router_agent` and
`router_model` are separate config keys (§8).

### 7.2 Class 3 metric — decided (`class3gate: gates-conditional`)

For classes 1, 2, and stratum D, the expensive tier found the defect by construction. Class-3
defects were missed by review, so the expensive tier may miss them too — a cheap tier can't be
blamed for that. Two numbers, only one gates:

- **Conditional recall** (of class-3 defects the expensive tier finds, how many survive the
  cascade) — **this gates.**
- **Expensive-tier absolute detection rate on class 3** — reported, not gating.

### 7.3 Discrimination and stopping controls

Two synthetic, free controls bracket every metric: **NULL** (everything cleared — recall 0, saving
maximal) and **FLOOD** (everything escalated — recall 1.0, saving 0). Per stratum and per class, a
real cheap tier must land strictly inside the bracket on both axes, or those fixtures are rebuilt
before anything is scored. **Positive control:** re-running the expensive tier on a sample must
re-find recorded class-1/2 defects at a high rate, or the fixtures — not the cheap tier — are judged
unreviewable in isolation.

**Decided:** dev/held-out split assigned before any cheap-tier prompt is written, at task/PR level
(no diff in both). Held-out scored once, after the prompt is frozen and its `git hash-object`
recorded. **There is no `blind-map.json`** — a deliberate departure from the prior protocol, since
the threat here is prompt overfitting (guarded by the split), not scorer bias (scoring is set
membership, no human judgement).

### 7.4 Ship bar — decided (`barshape: by-failure-mode`), non-uniform

- **Designs with an unrecoverable-miss class** (per-file, whole-change): a miss is a defect nobody
  looks at again. Bar: recall ≥ 0.98, Wilson 95% LB ≥ 0.95, target **N ≥ 142** per gated cell.
- **Designs whose failure degrades to baseline** (angle routing, cheap-as-explorer): a failure is a
  cost regression, not a lost defect. Bar: non-inferiority against the unaided expensive panel,
  cascade recall LB ≥ 0.90 of the unaided panel's point estimate, target **N ≥ 69**.

Neither bar goes above 0.95 LB — the marginal gain from N=239 at 0.97 LB is dominated by corpus
construction uncertainty (§7.5), not sampling error.

**Gate order:** 0. N floor met, else null for that cell. 1. Instrument discriminates (§7.3). 2. The
recall bar above. 3. Escalation/skip rate leaves a real saving. 4. Measured end-to-end cost < 0.80×
the non-cascade panel. **Bars 1 and 2 are the ship decision.** Failing 3 or 4 still ships the code,
behind its off-by-default flag, with the negative economics written up. Precision, hint quality,
context completeness, and class-3 absolute detection are reported and are **not** decision inputs.

**N pooling contract:** `N ≥ 142` per full `(model × stratum × class)` cell is 24 cells and
unreachable. The floor applies to the gated number **pooled across strata within one
`(model × class)`** — pooling across strata is allowed (buys power); pooling across classes is
forbidden (§5.1, destroys meaning). Per-stratum numbers are always reported alongside; if
per-stratum recall is more heterogeneous than sampling explains, the pooled figure is not reported
as the headline and the discrepant stratum is reported as the finding.

**Freezing contract:** stratum D and N fixtures frozen by a MANIFEST in the shape of
`docs/skill-evidence/arms/MANIFEST.md` — `git hash-object --no-filters` blob SHAs, a commit cell
that must contain the blob at the recorded path, header-resolved columns, a test re-checking every
row. Strata M and Q frozen the same way in the private corpus directory; only row count and the
manifest's digest are committed to the public repo. **Ledger:** every cheap-tier invocation counted
in an append-only ledger with per-stage ceilings, arithmetic checked by a test. Retries count.

### 7.5 Stated limitations (carried into the results writeup, not re-litigated)

1. Corpus construction, not model access, is now the largest limitation: every class is a filter
   over a *reachable* subset of defects, and class 3's cleanly-attributable defects (7 of 40
   candidates in quite-app) are plausibly the simpler ones — the measured ceiling may be optimistic
   in a direction no interval captures.
2. Stratum D ground truth is "what an Opus/Sonnet panel found and someone fixed" — recall against
   the expensive tier, never absolute.
3. Class 1 is "what a human caught and the author fixed"; class 2 is "what a bot nominated and a
   human accepted." Both miss what review missed entirely, which only class 3 supplies.
4. Class 1 rests on modular and neovim only (quite-app has essentially no human review).

## 8. Configuration contract

```toml
[review.cascade]
enabled = false            # DEFAULT, and it stays off in this run regardless of result
mode = "<undecided>"       # explorer | angle | file | change — SET BY TASK 0 (§3), not before.
                           # No default ships until the measurement picks one.
cheap_agent = "opencode"
cheap_model = "ko-ag/qwen3.6-35b-abliterated"
timeout_ms  = 120000       # expiry takes the degrade path of §2
```

`router_agent` / `router_model` are separate keys from the above (§7.1) since the ship decision is
per router model.

**`ko-ag/qwen3.6-35b-abliterated` is an abliterated build (safety tuning removed).** Recorded here
because omitting it would describe a different experiment. Under every design in §4, its output is
either a routing decision or a context bundle — never a finding that reaches a verdict.

**Execution contract:** the cheap tier runs **headless**, not as a herdr pane —
`opencode run --agent plan -m <model>`, verified working this session. Not stylistic: a cold
`opencode` reviewer pane swallows its seed and the panel cannot converge
(`docs/known-issues.md:3437`), so the pane path is closed for this backend; `opencode run` stdout is
a subprocess pipe, not the rendered terminal view `cli/src/code_review.rs:1` refuses to scrape.
Read-only via `--agent plan` with `--auto` absent; the `readonly_displace` protection
(`cli/src/config.rs:589`) runs first.

**Guard-with-artifact contract:** every set this run extends — config keys, the `mode` enum, the
cheap tier's output vocabulary, ledger columns, MANIFEST rows, fixture list, the class enum — has its
guarding test extended in the same change.

## 9. Deliverables

1. Task 0 cost instrumentation and its report.
2. Relational-defect ceiling for per-file routing (§4.4).
3. Corpus harvesters — class 1/2 attribution, class 3 blame-back — each reporting attrition.
4. Fixtures + MANIFESTs; D and N committed, M and Q private.
5. `provenance` typing, write guard, tests (§6).
6. Cheap-tier implementation for the selected mode plus the per-file control arm.
7. Cascade stage in `cli/src/code_review.rs`, behind `enabled = false`.
8. `docs/cascade-evidence/results.md` — controls, dev numbers, one held-out score per
   (model × stratum × class), each bar in order, ship decisions, §7.5 limitations, aggregates only.
9. Run ledger.

## 10. Out of scope

Flipping the `enabled` default on; changing the angle set, severity model, merge or resume path; a
second measurement instrument; fixing `docs/known-issues.md:3437` (the headless cheap tier routes
around it — the pane bug stays open and documented); any tier between qwen and opus.
